# الموقع الرسمي — د. ياسر سيد عبد السلام قطب

موقع شخصي احترافي (عربي RTL) مبني بـ React + TypeScript + Vite + Tailwind CSS.

## محتويات المشروع

- `index.html` — صفحة الدخول (خطوط عربية، RTL)
- `src/` — الكود المصدري (الأقسام، البيانات، التصميم)
  - `src/data/content.ts` — كل محتوى الموقع في ملف واحد للتعديل السهل
  - `src/sections/` — أقسام الصفحة (الواجهة، النبذة، المؤهلات، المناصب، الخبرات، الأعمال، البرامج، المقالات، التواصل)
- `public/` — ملفات عامة تُنسخ كما هي إلى الناتج
- `dist/` — ناتج البناء الجاهز للنشر (بعد تشغيل أمر البناء)
- `netlify.toml` — إعداد النشر على Netlify
- `package.json` / `tailwind.config.js` / `vite.config.ts` / `tsconfig.json` — ملفات الإعداد

## التشغيل محلياً

```bash
npm install
npm run dev
```

## البناء للنشر

```bash
npm run build
```

ينتج مجلد `dist/` الجاهز للاستضافة.

## النشر على Netlify — طريقتان

**الطريقة الأولى (الأسرع — سحب وإفلات):**
ارفع محتويات مجلد `dist/` فقط إلى app.netlify.com/drop — لا تحتاج أي بناء.

**الطريقة الثانية (من المصدر — للتطوير المستمر):**
ارفع المشروع إلى مستودع GitHub ثم اربطه بـ Netlify (Add new site ← Import an existing project).
سيقرأ Netlify ملف `netlify.toml` تلقائياً وينفذ البناء بنفسه عند كل تحديث.
